СВАДЕБНОЕ ПРИГЛАШЕНИЕ — ИНСТРУКЦИЯ

1. Распакуйте wedding_invitation_site.zip.
2. Откройте папку wedding_invitation_site в Visual Studio Code.
3. Откройте script.js и в самом начале замените:
   nameOne, nameTwo — имена;
   date — дата и время в формате ГГГГ-ММ-ДДTЧЧ:ММ:СС;
   dateLabel — дата, которая показывается на странице;
   venue, address — место проведения;
   mapUrl — ссылка на карту.
4. Фотографии находятся в папке images:
   person1.jpg и person2.jpg. Можно заменить их своими фото,
   сохранив эти имена файлов.
5. Откройте index.html через расширение Live Server в VS Code
   или просто двойным щелчком в браузере.

Форма RSVP сейчас показывает ответ на странице, но не отправляет его
организаторам. Для реального сбора ответов нужно подключить сервис формы
или настроить отправку на электронную почту.
